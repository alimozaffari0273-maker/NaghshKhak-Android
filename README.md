# NaghshKhak Android

A first Android WebView app for the NaghshKhak store.

- App label: نقش‌خاک
- Website: https://naghshkhak.ir
- Build: GitHub Actions > Build NaghshKhak APK
- Output: app/build/outputs/apk/debug/app-debug.apk

This initial APK is a web-connected shell. Store pages, product data, cart, checkout and account features must be implemented and maintained on the website/backend. A debug APK is for testing; a signed release APK/AAB is needed for public distribution.
